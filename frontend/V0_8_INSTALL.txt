COLORSHINE MES V2.0.8 - FULL SCREEN MODULE / SCREEN NUMBER NAVIGATION

WHAT CHANGED
- Permanent left sidebar removed after login. Application content now uses full screen width.
- New Modules button in the header opens the 6 business modules.
- Select a module to display the screens registered under that module.
- Every screen has a permanent 4-digit Screen No.
- Header Screen No box supports direct navigation. Type the number and press Enter/arrow.
- Direct URL is also supported: /screen/1101, /screen/4101, etc.
- Module dashboard foundation added for all 6 modules.
- Administration remains separate from the 6 business modules.
- Existing user access, GRN, RM Inventory, Quality, TDC, Reports and Master Data are retained.

INSTALL
1. Stop frontend (Ctrl+C).
2. Back up the current frontend folder.
3. Replace frontend files with this package.
4. Run: npm install
5. Run: npm run dev
6. Browser: Ctrl+F5

No database or backend migration is required for this UI/navigation update.
