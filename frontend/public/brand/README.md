# Colorshine brand assets

- `colorshine-logo.png` is bundled locally from an official Colorshine company document supplied with this project so the MES remains usable offline.
- The login brand panel also references the official product brochure hosted at:
  `https://colorshine.in/assets/Colorshine-Product-Brochure-BF6ZPujz.pdf`
- Official corporate and manufacturing imagery reference:
  `https://colorshine.in/about-us`
- Official product imagery reference:
  `https://colorshine.in/signature`
