Install
-------
Replace the existing frontend folder with this one, or copy its contents into:
D:\Colorshine\Color_MES\ColorshineMes\frontend

Then run:
  npm install
  npm run dev

Refresh browser with Ctrl + F5.

No backend or database changes are required.
