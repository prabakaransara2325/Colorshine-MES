COLORSHINE MES V2.0.8.4 - WORKING SCREENS TAB BAR

1. Run backend/sql/13_user_working_screens.sql in the colorshine_mes database.
2. Replace the backend and frontend files from the v0.8.4 update package.
3. Restart backend:
   cd D:\Colorshine\Color_MES\ColorshineMes\backend
   npm run dev
4. Restart frontend:
   cd D:\Colorshine\Color_MES\ColorshineMes\frontend
   npm run dev
5. In Chrome press Ctrl + F5.

BUSINESS RULES
- Maximum 8 processing screens open per user.
- Opening an already-open screen activates the existing tab.
- The system never automatically closes a working screen.
- On the 9th screen request, user must close one unused screen.
- Open working screens persist per user in PostgreSQL across refresh/login.
- Dashboard screens are not counted as processing tabs.
- Close / Close Others / Close All are supported.
