COLORSHINE MES V2 v0.10.8 - SIMPLE ACTIVE UI + MASTER COPY/EDIT

PURPOSE
-------
Keep the MES UI simple while development proceeds screen by screen.
Only currently implemented modules/screens are visible.
Add safe Copy-as-New + Edit maintenance to the active manufacturing masters.

INSTALL
-------
1. Stop backend and frontend.
2. Extract this full package over:
   D:\Colorshine\Color_MES\ColorshineMes
3. Run ONCE:
   backend\APPLY_V0108_ACTIVE_UI_CLEANUP.bat
4. Start backend and frontend.
5. Press Ctrl+F5 in Chrome.
6. Sign in as ADMIN.

EXPECTED UI
-----------
Visible business modules:
- RM Stores
- Planning
- Quality
- Reports
- Masters

Hidden for now:
- Production module (dashboard shell only)
- Maintenance module (dashboard shell only)
- Planning / Quality / Reports placeholder dashboards
- Legacy Reference Masters / combined Master Data screen

Masters Control Center is now Screen 7000 inside the Masters module only.
It is no longer shown in the ADMIN profile dropdown.

DATA SAFETY
-----------
The v0.10.8 cleanup does NOT delete/truncate master or business data.
It only changes active module/screen metadata and removes user shortcut/tab
rows that point to deliberately hidden screens.
