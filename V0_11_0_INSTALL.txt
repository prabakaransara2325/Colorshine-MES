COLORSHINE MES V2 v0.11.0 - TDC TEMPLATE + WORKFLOW
===================================================

SCOPE
- Company 2000 / Plant 2000 only.
- Quality screens 4200, 4201, 4202 and 4203.
- No Plant 1000 TDC is created in this release.

INSTALL
1. Stop frontend and backend.
2. Back up the Colorshine MES database.
3. Extract this package over:
   D:\Colorshine\Color_MES\ColorshineMes
4. Open backend folder.
5. If package.json changed, run once:
   npm install
   (v0.11.0 adds nodemailer for SMTP delivery.)
6. Run:
   APPLY_V0110_TDC_TEMPLATE_WORKFLOW.bat
7. Run:
   VERIFY_V0110_TDC.bat
8. Start backend and frontend.
9. Chrome: Ctrl+F5.
10. Footer must show MES V2 0.11.0.

ACTIVE QUALITY TDC SCREENS
4200 - TDC Template Master
4201 - TDC Register
4202 - TDC Create / Revise Wizard
4203 - TDC Approval

TEMPLATE RULE
- ACTIVE templates are immutable.
- To add/remove/change a characteristic on an ACTIVE format, use Copy as New Template.
- Enter a NEW Template Code and NEW Template Name.
- Make changes only on the copied DRAFT.
- Activate the new template when ready.
- Existing TDC versions never change when templates are changed.

FUTURE CATEGORY
- Quality -> 4200 -> Category -> create category + TDC prefix.
- Create a new template for the category (blank or Copy as New Template).
- Add existing reusable characteristics or create a new characteristic.
- Activate the template.
- No React/backend code change is required for a new category.

NEW CHARACTERISTIC
- Quality -> 4200 -> Characteristic.
- Create Code, Name, Group Code, Data Type, UOM and Value Mode.
- It is also created under the central MES Group Code engine.
- Add it to any DRAFT TDC template and choose its Wizard Section.
- Wizard tabs with no characteristics for the selected template are hidden automatically.

SYSTEM TDC NUMBER
- TDC No is never manually entered.
- Counter is Plant + TDC Prefix + Series.
- A missing Prefix + Series counter is created automatically at first use.
- Source-based initial next numbers:
  BGL/OEM -> BGL/OEM/0012
  BGL/DOM -> BGL/DOM/008
  CRFH/OEM -> CRFH/OEM/0003
  HRPO/CIPL -> HRPO/CIPL/0002
- Version is stored separately as V01, V02, V03...

VERSION CONTROL
- Draft can be saved before submission.
- Creator submission locks that version.
- Any later change uses New Version.
- Old versions stay permanently available.
- Previous APPROVED version remains effective until the new version receives final Plant Head approval.
- TDC cannot be deleted. Deactivate only, with mandatory reason.
- Deactivation does not rewrite the historical status of any saved TDC version.

APPROVAL
Creator -> QC Head -> PPC Head -> Plant Head -> Approved
Access groups:
TDC_CREATOR_2000
TDC_QC_HEAD_2000
TDC_PPC_HEAD_2000
TDC_PLANT_HEAD_2000
